# Java labs

Практичні роботи з дисципліни «Об'єктно-орієнтоване програмування на мові Java».

Конопля Іван, група Ін-42/1, варіант 1 (клас Clothes).

- ПР4 (тег `pr4`): клас Clothes, масив об'єктів, Maven, Git
- ПР5 (тег `pr5`): валідація, InvalidClothesException, меню, JUnit 5
- ПР6 (тег `pr6`): enum Size і Material, конструктор копіювання, статичний лічильник, агрегація (Wardrobe)
- ПР7 (тег `pr7`): наслідування (Pants, Shirts), поліморфізм, спільний ArrayList; статичні члени та агрегацію прибрано
- ПР8 (тег `pr8`): ще два класи ієрархії (Jeans extends Pants, FormalShirt extends Shirts), меню з вибором типу об'єкта
- ПР9 (тег `pr9`): читання об'єктів з файлу при запуску і запис при завершенні (input.txt, додатково input.json через Gson)
- ПР10 (тег `pr10`): пошук у колекції за назвою, типом, діапазоном ціни і розміром (підменю пошуку)
- ПР11 (тег `pr11`): клас Store (магазин) з ArrayList товарів і кількістю кожного товару, addNewClothes, пошук перенесено в Store
- ПР13 (тег `pr13`): Clothes став абстрактним і реалізує Comparable (сортування за назвою за українським алфавітом), новий клас Sweater, пункт меню 4 виводить відсортовані товари
- ПР14 (тег `pr14`): підменю сортування за назвою, ціною, роком випуску і кількістю, кожен критерій - анонімний клас Comparator

Збірка і тести:

```
mvn clean test
```

Запуск (Windows):

```
run.cmd
run-json.cmd
```

`run.cmd` працює з файлом `input.txt`, `run-json.cmd` з файлом `input.json`.

Формат `input.txt`: один товар у рядку, значення через `;`, перше значення це назва класу, останнє це кількість:

```
Sweater;назва;бренд;розмір;колір;матеріал;рік;ціна;кількість
Pants;...;обхват талії;довжина;кількість
Jeans;...;обхват талії;довжина;крій;щільність;кількість
Shirts;...;рукав;комір;кількість
FormalShirt;...;рукав;комір;запонки;без прасування;кількість
```

Рядки, що починаються з `#`, і порожні рядки пропускаються. Некоректні рядки пропускаються з повідомленням.
У `input.json` кількість записується в поле `quantity`.
Товари додаються в магазин методом `Store.addNewClothes`, тому якщо товар у файлі повторюється, кількості додаються.
Перед записом попередній вміст файлу копіюється в `input.txt.bak` (`input.json.bak`).
