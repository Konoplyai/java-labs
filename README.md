# Java labs

Практичні роботи з дисципліни «Об'єктно-орієнтоване програмування на мові Java».

Конопля Іван, група Ін-42/1, варіант 1 (клас Clothes).

- ПР4 (тег `pr4`): клас Clothes, масив об'єктів, Maven, Git
- ПР5 (тег `pr5`): валідація, InvalidClothesException, меню, JUnit 5
- ПР6 (тег `pr6`): enum Size і Material, конструктор копіювання, статичний лічильник, агрегація (Wardrobe)
- ПР7 (тег `pr7`): наслідування (Pants, Shirts), поліморфізм, спільний ArrayList; статичні члени та агрегацію прибрано
- ПР8 (тег `pr8`): ще два класи ієрархії (Jeans extends Pants, FormalShirt extends Shirts), меню з вибором типу об'єкта
- ПР9 (тег `pr9`): читання об'єктів з файлу при запуску і запис при завершенні (input.txt, додатково input.json через Gson)

Збірка і тести:

```
mvn clean test
```

Запуск (Windows):

```
run.cmd
run-json.cmd
```

`run.cmd` працює з файлом `input.txt`, `run-json.cmd` з файлом `input.json`.

Формат `input.txt`: один об'єкт у рядку, значення через `;`, перше значення це назва класу:

```
Clothes;назва;бренд;розмір;колір;матеріал;рік;ціна
Pants;...;обхват талії;довжина
Jeans;...;обхват талії;довжина;крій;щільність
Shirts;...;рукав;комір
FormalShirt;...;рукав;комір;запонки;без прасування
```

Рядки, що починаються з `#`, і порожні рядки пропускаються. Некоректні рядки пропускаються з повідомленням.
Перед записом попередній вміст файлу копіюється в `input.txt.bak` (`input.json.bak`).
